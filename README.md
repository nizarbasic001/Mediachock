# 🎬 Media Chock Downloader

**Media Chock Downloader** is a simple and powerful tool that allows you to install custom files directly onto your Nintendo Switch memory card.

---

## Features

- Download and install files directly to your memory card.
- Automatically replace existing files if they already exist.
- Extract ZIP files directly, preserving folder structure.
- Simple and user-friendly interface.
- Quick access to our YouTube channel for tutorials and updates.

---

## How to Use

1. **Download and run** the Media Chock Downloader application.  
2. **Choose your memory card** as the destination folder.  
3. **Select the files** you want to install.  
4. **Click "Download"** and wait for the process to finish.  
5. Once completed, **insert your memory card** into your Nintendo Switch.

## Notes

- Make sure the memory card is connected to your PC before starting the download.
- ZIP files are automatically extracted and any existing files are replaced.
- Always safely eject your memory card after installation.
